The pipeline

From repository to grounded answer

01

Connect your repo

Paste a public GitHub URL. Phoenix clones it and filters down to the files that matter.

02

Index into embeddings

Files are chunked and embedded, then stored in a vector index for fast semantic retrieval.

03

Ask in plain language

Ask what you actually want to know — "where does auth happen," "what does this function do."

04

Get a cited answer

Every answer points back to the file and line it was drawn from — verify it in seconds.

Why Phoenix

A codebase you don't understand isn't a dead end

Every developer has inherited a repo with no docs, a service nobody left notes on, or a codebase too large to read start to finish. Phoenix doesn't replace reading the code — it gives you a grounded way in: ask a question, get an answer pointing straight at the lines that actually answer it. What felt tangled becomes something you can navigate with confidence.
